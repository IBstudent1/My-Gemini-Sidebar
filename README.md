# My-Gemini-Sidebar
This is a simple extension created by an IB student. All it does is it opens Google Gemini in Google Chromes own Sidebar.

***To Install***
1. Extract the downloaded .zip file wherever you want it to be.
2. Open Chrome and enter "chrome://extensions" into your searchbar
3. In the top right of the extensions menu, turn on the developer mode (This is needed to install unpacked extensions)
4. In the top left select "Load Unpacked" and find where you extracted the downloaded file.
5. Select the downloaded file (1 folder deep. Should be named "My-Gemini-Sidebar-Release-v1")
6. Enjoy the extension.
